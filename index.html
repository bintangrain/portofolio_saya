      Tentang saya

      Saya Bintang Rain Heriawan, mahasiswa Prodi Pendidikan Teknologi Informasi, Fakultas Keguruan dan Ilmu Pendidikan, Universitas Sulawesi Barat.

      Saya tertarik pada pertemuan antara teknologi dan pendidikan: bagaimana sebuah antarmuka, media, atau aplikasi dapat membuat proses belajar lebih mudah dipahami. Website ini adalah tempat saya mendokumentasikan proses tersebut.
